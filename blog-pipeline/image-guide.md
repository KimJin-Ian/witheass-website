# 이미지 스타일 가이드

`image-maker.md`가 반드시 읽는다. 드림위드에스 홈페이지 디자인 토큰을 그대로 쓴다 (app/globals.css).

## 규격
- 홈페이지용 삽입 이미지: 16:9 (1200×675) — 본문 폭에 자연스럽게 맞음
- 네이버·인스타 겸용: 1:1 (1080×1080) 정사각형
- 배경: 크림/화이트 톤 기반 (다크 배경 금지 — 사이트가 라이트 톤이라 어울리지 않음)

## 색상 (globals.css 그대로)
```
navy-900   #0a1228   ← 진한 강조·헤드라인
navy-700   #1a2547   ← 보조 진한색
gold-600   #c4a661   ← 포인트 컬러 (숫자·아이콘·라인)
gold-500   #d4b870   ← 밝은 강조
gold-50    #fbf8f1   ← 카드 배경
white      #ffffff   ← 기본 배경
text-700   #464d5e   ← 본문 글자
```
하이라이트 컬러는 **gold-600 하나로 고정.** 색을 더 쓰지 않는다.

## 폰트
Pretendard (사이트와 동일). 시스템에 없으면 Malgun Gothic / Apple SD Gothic Neo로 대체.

## 고정 템플릿 4종 (이 4개 안에서만 고른다)

### ① 비교표 (comparison)
3열 표. 헤더 행은 navy-900 배경 + 흰 글자, 본문은 흰 배경 + gold-600 보더 라인.
예: 패키지 비교, 출판방식 비교

### ② 단계 다이어그램 (steps)
가로 화살표로 3~4단계 흐름. 각 단계는 원형 숫자(navy-900 배경) + 라벨.
예: 출간 프로세스, 안심 케어 3단계

### ③ 핵심 포인트 카드 (stat-card)
숫자 하나를 크게(gold-600, 48px+) + 짧은 설명 한 줄.
예: "인세 45%", "평균 3개월", "누적 890권"

### ④ 인용 강조 박스 (quote)
좌측 gold-500 세로 라인 + 이탤릭체 인용문. 홈페이지 blockquote 스타일과 동일.

## 텍스트 규칙
- 슬라이드 1장당 텍스트 20자 이하 (표 제외)
- 숫자는 항상 company-guide.md 기준 그대로. 반올림·과장 금지

## 제작 방식
그림을 그리는 게 아니라 **HTML/CSS로 슬라이드를 만들고 Playwright로 캡처**한다.
이유: 글자 잘림·정렬 어긋남이 없고, 브랜드 컬러가 항상 정확하게 유지된다.
