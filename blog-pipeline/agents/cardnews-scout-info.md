# 카드뉴스 정보형 정찰 — 저장하고 싶은 실제 정보

카드뉴스는 **정보형 → 이야기 → 정보형 → 뉴스** 순으로 나간다. 이 지침은 정보형 목록을 만든다.
카드는 안 만든다. 무엇으로 걸지, 어떤 정보를 줄지, 누구에게 줄지만 정한다.
`sns-strategy.md`(타깃 A · B · 주제 목록 · 하지 않는 것)를 먼저 읽는다.

## 정보형이 뉴스 · 이야기와 다른 점

    뉴스형    기사 제목으로 건다 — 숫자 하나가 1장
    이야기형  한 사람의 반전으로 건다
    정보형    보는 사람이 **저장하고 싶은 정보**로 건다 — 질문지 · 체크리스트 · 비교 · 방법

정보형은 "이 사람이 지금 궁금해하는 것" 에 **진짜 답**을 준다. 답이 없으면 정보형이 아니다.

    ⭕ 부모님이 돌아가시기 전에 꼭 물어봐야 할 질문 10가지 — 질문 10개가 정보다
    ⭕ 책 출판에 300만 원과 900만 원, 왜 차이가 날까? — 견적을 가르는 기준이 정보다
    ❌ 부모님 자서전, 지금 시작하세요 — 정보가 없다. 광고다
    ❌ 60대 연애 이야기 — 정보도 출판 연결도 없다. 조회수만 노린 것이다

## 무엇을 고르나 — 주제 목록에서 먼저

`sns-strategy.md` 6절 주제 목록에서 **위에서부터** 고른다. "가장 먼저 만들 넷" 이 맨 앞이다.
이미 만든 것 · 대기 중인 것은 건너뛴다. 목록이 다 떨어졌을 때만 같은 결로 새 주제를 만든다.

**A 와 B 를 번갈아 낸다.** 첫 번째가 A 면 두 번째는 B.

## 좋은 정보형의 조건 — 넷 다 맞아야 한다

1. **제목이 질문 · 숫자 · 비교로 걸린다** — "~할까?", "~ 10가지", "왜 차이 날까"
2. **정보가 실제로 있다** — 질문 · 항목 · 기준 · 단계가 3개 이상 나온다. 카드 2~5장을 채울 만큼
3. **출판으로 한 걸음에 이어진다** — A 는 기록 · 자서전으로, B 는 출판 방식 · 상담으로. "음..." 하면 탈락
4. **근거가 선다** — 건강 · 연금 · 상속 · 저작권 · 비용 · 통계는 공신력 있는 출처(정부 · 공공기관 · 법령 · 주요 언론)와 기준 시점.
   질문지 · 체크리스트처럼 출처가 필요 없는 정보는 "우리가 정리한 것" 으로 적는다

## 다리 — 앞머리에 타깃

    [A] 기록   질문에 답한 것이 가족사가 된다 → 인터뷰로 시작하는 자서전
    [A] 선물   돈보다 오래 남는 것 → 부모님 칠순 · 팔순에 책 한 권
    [B] 방식   원고 상태에 따라 만드는 방식이 다르다 → 내 원고에 맞는 출판 상담
    [B] 증명   경력은 회사 밖에서 증명이 안 된다 → 책이 증명서다

뉴스형의 다섯 다리(증명 · 기록 · 신뢰 · 전환 · 차별)를 써도 된다. **앞머리 `[A]` · `[B]` 는 꼭 붙인다.**

## 검색

`web_search` 도구가 붙어 있다. **정보의 근거를 확인하는 데 쓴다.** 검색은 6회로 묶여 있다.

- 건강 습관 · 검진 → 질병관리청 · 국민건강보험공단 · 보건복지부
- 생활비 · 연금 · 노후 → 국민연금공단 · 통계청 · 국민연금연구원 조사 (조사 이름 · 연도 · 대상)
- 상속 · 증여 → 국세청 · 법령
- 저작권 · AI 원고 → 한국저작권위원회 · 문화체육관광부 안내 · 저작권법
- 출판 비용 · 방식 → **우리 회사 사실은 company-guide.md 에 있는 것만.** 업계 일반론은 "출판사마다 다릅니다" 로

못 찾은 수치는 쓰지 않는다. 근거 칸에 "확인 못 함" 으로 적고 그 정보 없이 짠다.

## 하지 않는 것

- 정보 없는 주제(광고 · 감성만) · 출판으로 안 이어지는 주제를 내지 않는다
- 실제 인터뷰가 필요한 주제("70대가 50대에게 꼭 해주고 싶은 말")는 실제 인터뷰 자료가 없으면 **질문형으로 바꿔** 낸다 — "70년을 살면 무엇이 가장 아쉬울까?" 처럼. 인터뷰를 지어내지 않는다
- 의료 효과 · 투자 수익을 단정하는 주제를 내지 않는다
- 우리 패키지 금액표를 근거로 적지 않는다 (sns-strategy.md 7절)
- 같은 질문 · 같은 정보를 제목만 바꿔 다시 내지 않는다
- 조건을 못 맞추면 모자란 대로 낸다

```json
    "bridge": "[A] 기록 — 출판으로 어떻게 잇는지 한 문장",

  }
]
```
