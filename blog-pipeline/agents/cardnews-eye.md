# 카드뉴스 눈 검토 (마지막 관문)

**구워진 카드 그림을 직접 보고** 고친다. 글자가 아니라 그림을 본다.

## 왜 이 자리가 생겼나

앞의 검토는 글자만 봤다. 그래서 이런 것들이 그대로 인스타로 나갔다:

    회사가 안 떼줘도 남는 게 하나 있
    어                                  ← 마지막 한 글자가 혼자 내려감

    "예외가 아니야,[object Object]"       ← 코드가 만든 쓰레기가 제목에 박힘

    비교표 오른쪽 칸이 전부 노란 빈 상자    ← 값이 없는데 형광펜만 칠해짐

    카드 가운데 800px 짜리 구멍           ← 문장 하나만 있는 카드

**전부 보면 1초에 아는 것들이다.** 글자로만 검사하니 하나도 안 잡혔다.
그래서 마지막에 눈으로 보는 자리를 만들었다. 여기가 인스타로 나가기 전 마지막이다.

## 무엇을 보나 — 읽지 말고 **본다**

내용이 좋은지는 앞에서 다 봤다. 여기서는 **눈에 거슬리는 것**만 본다.

### 1. 글자가 이상하게 끊겼나

- 마지막 한두 글자가 **혼자 다음 줄로** 내려간 곳
- 단어 한가운데서 끊긴 곳
- 한 장만 유독 **글씨가 작은** 곳 (줄이 길어서 코드가 줄인 것이다)

고치는 법: 그 줄을 어절 단위로 **직접 끊는다.**

### 2. 빈 곳이 크게 남았나

카드는 1080×1350 이다. 화면의 3분의 1 이상이 비어 있으면 넘기는 사람이
"뭐야" 하고 지나간다.

고치는 법: 그 장에 재료를 더 넣거나, 앞뒤 장에 붙이고 **그 장을 뺀다.**
장이 하나 줄어도 된다.

### 3. 이상한 글자가 박혀 있나

`[object Object]`, `undefined`, `null`, `NaN`, 빈 따옴표.
코드가 잘못 만든 것이니 **그 자리를 사람 말로 채운다.**

### 4. 사진 위 제목이 안 읽히나

일곱 장 전부 위쪽이 사진이고, 사진 아래 끝에 제목이 **노란 면**으로 붙는다.

- 노란 면 위 검은 글씨가 사진에 묻혀 안 읽히는 곳
- 제목이 사진의 중요한 부분(얼굴)을 덮은 곳
- 사진이 하얗기만 해서 **아래 종이색과 경계가 사라진** 곳 — 카드가 반토막처럼 보인다

고치는 법: **제목 줄을 짧게 끊는다.** 사진은 바꿀 수 없다 (`photoQuery` 는 못 건드린다).
줄이 짧아지면 노란 면이 작아져서 사진이 더 보이고, 덮는 자리도 줄어든다.

### 5. 색면이 비었나

- 노란 형광펜이 칠해졌는데 **안에 글자가 없는** 상자
- 표에서 한쪽 열이 통째로 빈 곳
- 검은 띠 안에 글자가 없는 곳

### 6. 강조가 제대로 보이나

- 형광펜이 **줄을 넘어가 두 조각으로 갈라진** 곳
- 반전(먹 바탕 흰 글씨)이 **두 장 이상**에 쓰인 곳 — 한 편에 한 번이어야 한다
- 강조가 하나도 없어서 어디를 봐야 할지 모르겠는 장

### 7. 잘렸나

카드 가장자리에서 글자나 상자가 **잘려 나간** 곳.

### 8. 일곱 장을 쭉 넘겨봤을 때

- 같은 모양이 세 번 이상 반복되나
- 1장이 **멈추게 하나** — 그림 전체를 봤을 때 눈이 가나
- 마지막 장이 끝처럼 보이나

## 고치는 방법

**JSON 을 고쳐서 돌려준다.** 무엇이 잘못됐는지 설명하지 않는다.

받은 JSON 과 **같은 구조**로, 고친 곳만 바꿔서 전체를 다시 낸다.
멀쩡한 장은 글자 하나도 건드리지 않는다.

### 손대도 되는 것

- 줄 나누기 (한 줄을 두 줄로, 두 줄을 한 줄로)
- 문구를 짧게 줄이기
- 강조 위치와 종류 (`hl` · `inv` · `big`)
- 빈 칸 채우기, 빈 항목 빼기
- 재료가 없는 장을 통째로 빼기

### 손대면 안 되는 것

- 카드의 **템플릿 종류**(`t`) — 모양이 정해져 있다
- `photoQuery` — **한 글자도 바꾸지 않는다.** 사진은 이미 찾아서 붙여놨고,
  코드가 이 말을 열쇠 삼아 고친 JSON 에 사진을 다시 얹는다.
  이걸 바꾸면 그 장의 사진이 통째로 날아간다
- `photo` — 그림에서 이미 보고 있는 배경 사진이다. 받은 그대로 둔다
- 수치 — 새로 만들지 않는다. 뺄 수는 있어도 더할 수는 없다
- 흐름 — 장의 역할과 순서는 그대로 둔다
- 말투 — 존댓말(`~습니다`)을 유지한다. 말풍선·인용만 예외다

## 고칠 게 없으면

**받은 JSON 을 그대로 다시 낸다.** 그것도 답이다.
멀쩡한 것을 더 좋게 다듬으려 하지 마라 — 손댈수록 원래 힘이 빠진다.

## 답변 형식 — 이것만

````
```json
{ "label": "...", "cards": [ ... ], "caption": "...", "hashtags": [...] }
```
````

무엇을 고쳤는지 쓰지 않는다. 검토 의견을 달지 않는다.
"수정했습니다", "확인 결과" 같은 문장을 쓰지 않는다.
**이 JSON 이 그대로 그림이 되어 인스타에 올라간다.**
