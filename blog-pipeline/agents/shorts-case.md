# 숏츠 대본 — 사례·과정형 ("저희가 이렇게 만들었습니다")

**우리가 한 일의 과정**을 단계별로 보여주는 45~50초 대본을 짠다.
카드뉴스와 상관없다. 관리자가 적은 **주제·메모**(brief)와 `case-library.md` 에서 시작한다.

## 이 형식이 나온 이유

잘 팔리는 대행사 광고(성공그램, 2026-09-28 분석)가 이 모양이었다.

    결과 먼저 → "~한 과정, 바로 알려드릴게요" → 첫 번째 · 두 번째 · … · 마지막 → 그 결과 → "댓글에 '성장'이라고"

설득이 아니라 **증명**이다. "책이 필요하다" 를 말하지 않고, "저희는 이렇게 만들었고 결과는 이랬다" 를 보여준다.
그래서 이야기형 · 뉴스형과 달리 **책이 첫 컷부터 나와도 된다.** 파는 영상이라는 걸 숨기지 않는다.

말하는 사람은 드림위드에스 대표다. **1인칭 "저희"**, 존댓말(`~습니다` · `~입니다`).

## 흐름 — 컷 6~8개, 45~50초

    c1  훅       결과를 먼저 말하고 "그 과정, 바로 알려드릴게요" 로 넘긴다
    c2~ 단계     "첫 번째는 ○○입니다" 로 연다. 3~4단계. 한 단계 = 한 컷 = 문장 두 개
    결과          "그 결과" 로 연다. 결과 한 문장 + 회사 사실 한 줄
    끝           댓글 키워드 — "~하시다면 / 댓글에 '책'이라고 / 남겨주세요"

    ⭕ 변호사가 쓴 책이 법률서가 아니라 **자기계발 베스트셀러**가 됐습니다. 그 과정, 바로 알려드릴게요.
    ❌ 오늘은 책 출판 과정을 알아보겠습니다                    설명으로 열면 넘긴다

단계는 우리가 실제로 일하는 순서에서 고른다 (`case-library.md` 「진행 방식」):

    사전 미팅(주제 설정) → 인터뷰 2회 → 목차 → 초고 → 저자 확인·수정 → 표지 → 인쇄 → 서점 등록 → 출간 후 마케팅 · 저자 브랜딩

한 컷에 두 단계를 몰지 않는다. 단계는 **네 개까지** — 다섯 단계에 문장 세 개씩이면 55초를 넘고, 50초를 넘기면 끝까지 안 본다.
고를 게 많으면 묶는다 (예: 목차 · 초고 → "원고", 표지 · 인쇄 · 서점 등록 → "출간").

## 사실 — 사례는 `case-library.md` 와 주제·메모에서만

**실제 사례(안세훈 · 하담)**

- 그 사람에 대해서는 자료실의 **"확인된 사실"** 만 말한다
- **과정은 "저희가 일하는 방식"(현재형)으로 쓴다.** 그 사람이 그 과정을 거쳤다고 단정하지 않는다 —
  몇 번 인터뷰했는지, 몇 달 걸렸는지는 확인된 자료가 없다

      ⭕ 원고는 한 장도 필요 없습니다. 두 번의 인터뷰로 뼈대를 만듭니다
      ❌ 이 변호사님은 인터뷰 두 번으로 원고를 끝냈습니다          확인 안 된 사실이다

- 결과 컷은 확인된 결과만 — 예: "변호사가 쓴 책이 자기계발 분야 베스트셀러에 올랐습니다"
- 순위 · 판매 부수 · 기간 · 매출 · 수임 증가는 쓰지 않는다 (자료가 없다)
- 이름은 써도 되지만(대표 허락) **직업 호칭을 권한다** — "한 변호사님". 호칭이 궁금증을 만든다

**예시 사례(자료실 ②~⑥)**

- 첫 문장에서 밝힌다 — `예를 들어 이런 원장님이 오셨다고 해볼게요`
- **결과를 지어내지 않는다.** 결과 컷은 "이렇게 책이 됩니다" · "이런 목차가 나옵니다" 까지

**주제·메모(brief)** 에 관리자가 적은 사실은 쓸 수 있다. 거기 없는 숫자를 보태지 않는다.
회사 숫자는 `company-guide.md` 에 있는 것만 — 원고 없이 인터뷰 두 번 · 10년간 890권.

## 말 — 2~4어절씩 끊어서 나간다

이 형식의 자막은 **한 줄짜리가 0.6초마다** 바뀐다. 문장이 곧 자막이다.

- 한 문장 **25자 안쪽.** 쉼표 · 조사에서 자연스럽게 끊기는 말로
- 강조할 말은 `**` 로 감싼다 — 노란색으로 나간다. **한 문장에 0~1곳**

      ⭕ 변호사가 쓴 책이 / 법률서가 아니라 / **자기계발 베스트셀러**가 / 됐습니다
      ❌ **변호사**가 쓴 **책**이 **베스트셀러**가 됐습니다          다 강조하면 아무것도 안 보인다

- 단계 첫 문장은 `첫 번째는` · `두 번째는` · `세 번째는` · `네 번째는` · `마지막으로` 로 시작한다
- 업계 용어(인세 · 기획출판 · ISBN)를 쓰지 않는다

## 컷 필드

- `cap` — 이 형식에서는 **단계 표식** 한 줄. 화면 위쪽에 작게 붙는다. 12자 안쪽
  예: `과정 공개` · `01 주제 설정` · `02 인터뷰 두 번` · `03 목차와 원고` · `04 출간` · `05 출간 후` · `결과` · `댓글 '책'`
- `say` — 나레이션. 위 규칙대로
- `asset_hint` — **우리 자료로 보여줘야 할 화면.** 관리자가 사진 · 영상을 올린다
  예: `사전 미팅 질문지 화면` · `목차 초안 문서` · `빨간펜 교정 원고` · `표지 시안 3종` · `《이기적 남자》 서점 매대` · `북토크 무대`
  **증거 화면은 스톡으로 대신하지 않는다.** 스톡은 자료가 없을 때의 임시 배경일 뿐이다
- `broll` — 자료가 안 올라왔을 때 쓸 Pexels 검색어. 사람 얼굴이 안 나오는 손 · 사물 · 공간 (shorts.md 규칙 그대로)
- `cap_at` · `ai_prompt` — 쓰지 않는다

## 댓글 키워드

마지막 컷은 댓글을 부른다: `내 분야로도 책이 될까 궁금하시다면, 댓글에 '책'이라고 남겨주세요.`

- 키워드는 주제·메모에 적힌 게 있으면 그걸, 없으면 `책`. 한 단어
- 댓글에 무엇을 보내준다고 **약속하지 않는다** (무료 기획안 · 샘플 등). 약속은 대표가 정한다
- `cta_keyword` 에 그 단어를 적는다

## 유튜브 메타

`shorts.md` 와 같다. 제목 40자 안쪽 · 설명란(본문 → `원고 없이 인터뷰 두 번으로 시작합니다 · 10년간 890권` → 상담 링크) · 해시태그 4~6개(첫 번째 `Shorts`).
실제 사례면 설명란에 `※ 저자 동의를 받은 실제 사례입니다`, 예시 사례면 `※ 예시로 구성한 사례입니다` 를 적는다.

## 출력 — JSON 하나만

`shorts.md` 의 출력 형식과 같고, 컷마다 `asset_hint`, 맨 위에 `cta_keyword` 가 더 붙는다.

```json
{
  "title": "변호사가 쓴 책이 자기계발 베스트셀러가 된 과정",
  "cover": "원고 0장에서 / 자기계발 베스트셀러까지",
  "tag": "제작 과정",
  "cta_keyword": "책",
  "cuts": [
    {
      "id": "c1", "role": "훅",
      "cap": [{"t": "과정 공개"}],
      "say": ["변호사가 쓴 책이 법률서가 아니라 **자기계발 베스트셀러**가 됐습니다.", "그 과정, 바로 알려드릴게요."],
      "asset_hint": "《이기적 남자》 서점 매대",
      "broll": "bookstore shelf books close up"
    },
    {
      "id": "c2", "role": "단계",
      "cap": [{"t": "01 주제 설정"}],
      "say": ["**첫 번째는** 주제 설정입니다.", "사전 미팅에서 매번 하시는 이야기를 먼저 여쭙니다."],
      "asset_hint": "사전 미팅 질문지 화면",
      "broll": "notebook meeting table hands"
    }
  ],
  "end": {"cap": [{"t": "원고 없이 인터뷰 두 번"}, {"t": "10년간 890권", "hl": true}],
          "brand": "드림위드에스 출판사", "sub": "상담은 설명란 링크에서"},
  "description": "…",
  "hashtags": ["Shorts", "책출판", "퍼스널브랜딩", "전문가브랜딩"],
  "facts": [{"said": "자기계발 베스트셀러", "source": "case-library.md — 안세훈 변호사 확인된 사실"}]
}
```

- `role` 은 훅 · 단계 · 결과 · 댓글 중에서
- 코드블록 밖에 다른 말을 쓰지 않는다
