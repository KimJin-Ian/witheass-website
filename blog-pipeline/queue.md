# 주제 고르는 규칙

주제 목록 자체는 이제 이 문서에 없다. admin의 **주제 목록** 화면(`pipeline_topics` 표)에 있다.
세 쪽에서 목록을 건드리기 때문이다 — 발행 후 완료 처리, 자동 보충, 사람의 편집.
문서 하나를 세 곳에서 고치면 서로 덮어쓴다. 이 문서는 **어떤 주제를 고를지**만 정한다.

## 언제 채우나
남은 주제가 5개 밑으로 떨어지면 자동 실행이 스스로 15개까지 채운다.
미리 채우고 싶으면 주제 목록 화면에서 "주제 더 뽑기"를 누른다.

## 멈추지 않는 것이 우선이다
3일에 한 편이 끊기면 검색 노출이 무너진다.
**주제가 없다는 이유로 발행을 거르지 않는다.**
새 소재가 없으면 이미 쓴 주제를 다른 각도로 다시 쓴다 — 그래도 된다.
글이 실제로 겹치는지는 품질검사 G5(기존 글과 30% 이상 겹치면 차단)가 판단하므로,
주제 단계에서 미리 아낄 필요가 없다.

## 주제를 찾는 순서

### 1. 아직 안 다룬 검색어
사람들이 실제로 검색창에 칠 법한 말을 쓴다.
"출판사 추천" 같은 큰 말은 이미 큰 사이트들이 차지하고 있다.
**상황이 붙은 구체적인 말**이 검색에서 이긴다.

| 약한 주제 | 강한 주제 |
|---|---|
| 자비출판 | 원고 없이 인터뷰만으로 책 내는 법 |
| 출판 비용 | 계약금 내고 마음이 바뀌면 어떻게 되나 |
| 출판사 추천 | 의사가 책을 내면 병원에 뭐가 달라지나 |

### 2. 이미 쓴 주제의 다른 각도
같은 키워드라도 아래가 다르면 다른 글이다. **각도를 반드시 적는다.**

- **독자가 다르다** — 처음 쓰는 사람 / 이미 계약해본 사람 / 대표 / 전문직 / 은퇴 준비자
- **상황이 다르다** — 계약 전 / 계약 후 / 출간 후 / 실패를 겪은 뒤
- **형식이 다르다** — 비교표 중심 / 절차 안내 / 오해 바로잡기 / 사례 / 체크리스트
- **감정이 다르다** — 불안을 덜어주기 / 판단 기준 주기 / 결정을 밀어주기

### 3. 시의성
연말 결산, 신년 계획, 세금·정산 시기, 강연 시즌, 출판 관련 제도 변경.

## 하지 않는 것
- 이미 목록에 있는 키워드를 각도 없이 그대로 다시 내지 않는다.
- 회사가 실제로 모르는 분야는 내지 않는다 (`company-guide.md` 밖의 이야기).
- 낚시 제목을 만들지 않는다. 검색어를 그대로 쓴다.
- 경쟁사를 지목하는 주제를 내지 않는다.

## 우선순위
사람이 직접 추가한 주제가 맨 앞으로 간다. 자동으로 뽑힌 주제는 그 뒤에 붙는다.
순서는 주제 목록 화면에서 ↑↓ 로 바꾼다. 위에서부터 하나씩 나간다.
