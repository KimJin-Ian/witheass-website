## 조립 단계에서 내린 판단 — 표를 채널별로 다르게 처리

**AI는 이미지 속 글자를 읽지 못하므로**, 표를 PNG로만 두면 AEO 효과가 0이 된다.

## ✅ 해결 완료 — 사이트 CSS에 표 스타일 추가 (2026-08-17, 사람 승인 후 처리)

`app/globals.css` 의 `.blog-article-body` 에 `table / th / td` 스타일이 없어서
표가 테두리 없는 맨 텍스트로 나오는 문제가 있었다. 아래와 같이 추가함.

- 헤더: navy-900 배경 + 흰 글자, 상단 모서리 라운드
- 짝수 행: gold-50 배경 (얼룩말 줄무늬)
- 첫 열: 굵게 + `white-space: nowrap` (항목명 역할)
- 숫자 정렬: `font-variant-numeric: tabular-nums`
- 600px 이하: 표만 가로 스크롤 (페이지 본문은 안 밀림)

### 이 과정에서 잡은 버그 1건
처음에 `display: block; overflow-x: auto` 를 표 기본값으로 넣었는데,
**`display:block` 이 `width:100%` 를 무력화시켜 표가 본문 폭의 절반만 차지**했다.
→ 기본은 `display: table`, 좁은 화면(600px 이하)에서만 `display: block` 으로 전환하도록 수정.
→ 캡처로 재확인해 본문 폭 100% 채우는 것 확인. `npm run build` 통과.

**앞으로 모든 블로그 글에 자동 적용되므로 이 작업은 재발생하지 않는다.**
