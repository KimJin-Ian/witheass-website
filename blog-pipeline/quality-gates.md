# 품질 검사 — 발행 관문

사람 승인 단계가 없다. **이 8종 검사가 글과 세상 사이의 유일한 관문이다.**
하나라도 실패하면 발행하지 않고 `blocked` 상태로 남기고 알림을 보낸다.

> 왜 이렇게 엄격한가: 이 사이트에는 과거 검수 없이 자동 발행된 저품질 글 72건이
> 쌓여 사이트 전체 검색 신뢰도를 깎은 전례가 있다. 자동 발행을 하려면
> 사람 대신 검사가 그 역할을 해야 한다.

---

## G1. 최소 분량
```
기준   본문 1,500자 이상 (공백·마크다운 기호 제외)
근거   seo-guide.md — 네이버 D.I.A 최소 기준
실패시 blocked
```
상한은 두지 않는다. 다만 3,500자를 넘으면 경고만 남기고 통과시킨다.

## G2. 숫자 대조 ⭐ 가장 중요
```
기준   본문의 모든 금액·비율·기간이 company-guide.md 값과 일치
방법   본문에서 숫자 패턴 추출 (만원 / % / 개월 / 주 / 년 / 권 / 회)
       → company-guide.md 에 같은 값이 있는지 대조
실패시 blocked + 불일치 항목과 위치를 기록
```
**근거 없는 가격이 공개되면 되돌리기 어려운 신뢰 문제가 된다.**
company-guide 에 없는 숫자는 "상담 시 안내"로 바꾸거나 문장을 지운다.

예외 — 대조 대상에서 제외:
- 일반 상식 수치 (2014년 표준계약서 제정 등 출처가 본문에 명시된 것)
- 경쟁 시장 수치로 출처가 함께 적힌 것 ("한 업체 자료 기준" 등)

## G3. 금지 표현
```
기준   style-guide.md 금지 목록 0건
목록   업계 최고 / 국내 1위 / 무조건 / 최고의 / 가장 저렴 /
       100% 보장 / 확실히 성공 / 반드시 성공
실패시 blocked
```
의료·출판 모두 과장광고 규제 대상이다. 예외 없이 막는다.

## G4. 키워드 밀도
```
기준   주요 키워드 출현 비율 3% 이하
방법   (키워드 등장 횟수 × 키워드 길이) / 전체 글자수
근거   seo-guide.md — 네이버 어뷰징 판정 회피
실패시 blocked
```
과거 72건이 정확히 이 문제(같은 키워드 반복)로 저품질 판정을 받았다.

## G5. 기존 글 중복도
```
기준   이미 발행된 글과 30% 이하
방법   blog_posts 에서 최근 100건 본문을 가져와
       3-gram 기준 자카드 유사도 계산
실패시 blocked
```
같은 주제를 다시 쓰면 구글이 중복 콘텐츠로 판단해 둘 다 손해를 본다.

## G6. 실명·미확인 표시 잔존
```
기준   아래 문자열 0건
목록   [확인필요] / [저자 확인 필요] / TODO / FIXME /
       company-guide.md 의 실명 사례 목록에 있는 이름
실패시 blocked
```
동의받지 않은 실명이 공개되면 개인정보 문제가 된다.

## G7. 답변 우선 (2026-08-25 추가)
```
기준   본문 첫 문단 80자 이상 (권장 100~180자)
근거   seo-guide.md 5번 — AI 는 페이지가 아니라 문단 하나를 떼어 인용한다.
       첫 문단이 "~하는 분들이 많습니다" 같은 공감 문장이면 인용할 답이 없다.
방법   첫 <p> 의 글자 수 (태그·공백 제외). 소제목별 첫 문단 길이는 참고용으로 함께 표시
실패시 blocked
```
답인지 아닌지는 기계가 가릴 수 없으므로 길이로 본다.
24자짜리 문단은 답일 수가 없다는 것이 판정 근거다.
길이만 늘려서 통과시키라는 뜻이 아니다 — **제목이 던진 질문에 바로 답하면 자연히 이 길이가 된다.**

## G8. 자립 문단 (2026-08-25 추가)
```
기준   ① 앞 문맥에 기대는 표현 3건 미만
       ② "드림위드에스" 언급 ≥ max(2, 소제목 수 × 0.3)
근거   seo-guide.md 6번 — 문단 하나를 떼어냈을 때 뜻이 온전해야 인용된다
방법   ① `앞서 말했듯` `이 방식은` `그것은` 등 문맥 의존 표현 검출
       ② 본문 내 회사명 등장 횟수와 H2 개수 비교
실패시 blocked
```
①은 한두 번은 봐준다. 세 번 넘게 나오면 글 전체가 앞뒤에 묶여 있다는 뜻이다.
②는 "저희"만 쓰인 글을 막기 위한 것이다. 떼어놓으면 누구 이야기인지 알 수 없어 인용되지 않는다.
`style-guide.md` 의 "저희" 1인칭은 그대로 두되, **구역마다 한 번은 이름이 나와야 한다.**

## 판정 후 동작

| 결과 | 동작 |
|---|---|
| 8종 전부 통과 | `blog_posts` 에 `status='published'` 로 삽입 → 사이트 즉시 노출 |
| 1종 이상 실패 | `pipeline_runs.status='blocked'` + 실패 사유 기록 + 알림 |

**실패한 글은 자동 재시도하지 않는다.** 같은 지침으로 다시 만들면 같은 결과가 나온다.
사람이 admin에서 원인을 보고 지침을 고쳐야 다음 사이클이 개선된다.
