# 톤 가이드

`writer.md`가 반드시 읽는다.
원본: `서진씨 프로젝트/_out/녹음파일_분석_보고서.md` (상담·미팅 녹음 20건, 144,000자 분석).
이서진 대표의 실제 말투를 분석한 자료 기반이며, **말투를 그대로 옮기지 말고 글에 맞게 증류**한다.

## ⚠️ 중요 — 구어체를 그대로 옮기지 말 것
녹음에서는 "그래서 이제", "약간", "사실" 같은 추임새와 "저희가 900만 원에 이제~" 식으로
말을 길게 이어가지만, **이건 말할 때 리듬이지 글로 옮기면 늘어지고 가독성이 떨어진다.**
아래 표처럼 **말투의 핵심 태도만 가져오고, 문장은 짧게 정리**한다.

| 실제 말투 (구어) | 블로그 글로 옮길 때 |
|---|---|
| "그래서 이제 목차를 가지고 피드백을 주시면, 보통 한 두세 번 안에 완성이 되거든요" | "목차 피드백은 보통 2~3회 안에 완성됩니다." |
| "저희가 이제 900만 원에... 목차를 일주일 내로 보내드려요" | "900만원 패키지는 목차 초안을 1주일 안에 받아보실 수 있습니다." |
| "편하게 말씀해 주시면 정확한 견적 바로 드릴 수 있어요" | "분량과 마감일만 알려주시면 바로 견적을 안내해드립니다." |

## 어조
- 정중하되 딱딱하지 않게. "~합니다" 기본, 가끔 "~해요"로 숨 고르기
- 광고 문구 대신 정보 전달자 톤. "저희가 최고입니다"류 절대 금지
- 독자의 실제 고민을 먼저 인정한 뒤 정보로 들어간다
- 문장은 짧게 끊는다 (실제 말투는 길게 이어가지만, 글에서는 그러면 안 됨)
- "저희가/저희는"으로 회사를 지칭 (이서진 대표 본인이 가장 많이 쓰는 1인칭)
  - **단, 각 소제목 구역에서 처음 회사를 가리킬 때는 "드림위드에스 출판사"로 적는다**
    (2026-08-25 추가) — AI는 문단 하나만 떼어 인용하는데, "저희"만 있으면
    떼어놓았을 때 누구 이야기인지 알 수 없어 인용되지 않는다.
    이름을 한 번 밝힌 뒤 같은 문단에서 다시 가리킬 때는 "저희"로 받는다.
    톤을 바꾸라는 말이 아니라 구역마다 한 번은 이름이 나와야 한다는 뜻이다.
    자세한 이유는 `seo-guide.md` 6번.

## 절대 쓰지 않는 표현
- "업계 최고", "국내 1위", "무조건", "무조건 성공"
- 근거 없는 "많은 분들이", "다들" (숫자로 바꿀 것 — company-guide.md 참고)
- 지나친 감탄 부호 남발 (문단당 최대 1개)
- 카톡체 표현("넵", "ㅋㅋ", "~욥") — 이건 실제 카톡 톤이지 블로그 글 톤이 아니다

## 실제 설득 패턴 5단계 (녹음 분석에서 추출 — 글의 논리 골격으로 사용)
이서진 대표가 상담에서 실제로 쓰는 클로징 순서. `strategist.md`의 ①~⑦ 골격과 자연스럽게 맞물린다.

1. **의뢰자 상황 진단** — "~하려고 하시는 거죠?" 식으로 독자 고민을 먼저 정리해준다 (①에 대응)
2. **일반 시장 문제 짚기** — "다른 데는 보통 ~한데" 식 대비 구도 (②에 대응)
3. **우리 솔루션을 숫자로** — 추상적 설명 대신 "900만원 / 목차 1주일 내 / 인터뷰 2회" 식 구체 수치 (⑤에 대응)
4. **사회적 증거** — "건설사 대표님이 한 번 책을 내시고..." 식 실제 사례 즉석 인용 (④에 대응)
5. **부드러운 클로징** — 압박 없이, "편하게 말씀해 주시면" 식 낮은 진입장벽 (⑦에 대응)

## ⚠️ 상담과 블로그의 차이 하나 — 가격 공개 타이밍
상담에서는 **가격을 먼저 말하지 않는 게 클로징 노하우**다 ("두 가지만 알려주시면 견적 드릴게요").
하지만 블로그는 정반대다 — `seo-guide.md`에 정리했듯 **AI 검색은 숫자가 먼저 나온 문장을 인용한다.**
→ 블로그 글에서는 상담 톤을 따르지 말고, **가격·인세율·기간을 초반부터 구체적으로 공개**한다.
이 지점만 상담 방식과 의도적으로 다르게 간다.

## 자주 강조되는 개념 (녹음 키워드 빈도 상위 — 자연스럽게 녹여 쓸 것)
목차 > 마케팅 > 기획 > 블로그 > 강연 > 검색 > 인터뷰 > 베스트셀러
- "목차"가 압도적 1위 — 회사의 핵심 훅은 "목차부터 잡아드린다"
- "마케팅(112회) >> 인쇄(45회)" — 이 회사는 인쇄업이 아니라 마케팅 회사라는 자기 인식이 강함.
  글에서도 "책을 만들어드립니다"보다 "책으로 검색되게 만들어드립니다" 쪽 앵글이 더 회사답다

## 참고 문장 (실제 사이트에서 가져온 문어체 톤 샘플)
> "출판사는 많은데, 견적서를 받아봐도 무엇이 다른지 알기 어렵습니다. 같은 '900만원'이라도 포함 범위가 완전히 다르기 때문입니다."

> "흔한 오해 — '자비출판은 돈 주고 내는 거라 급이 낮다'고 생각하시는 경우가 많습니다. 하지만 ISBN이 발급되고 전국 서점에 유통되면 기획출판과 서지 정보상 차이가 없습니다."

이 정도의 담백함·구체성·정직함을 기준으로 삼는다.
